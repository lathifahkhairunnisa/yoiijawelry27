Panduan Penggunaan

Website ini terhubung ke Google Sheets sebagai database gratis. Berikut cara pakainya.

Untuk Pengunjung

  • Lihat produk — Produk diambil otomatis dari database.
  • Keranjang — Tambah produk, keranjang tersimpan di browser kamu.
  • Checkout — Isi nama & nomor WA → pesanan tersimpan di database + terbuka WhatsApp.
  • Custom Order — Isi form custom → request masuk ke database + terbuka WhatsApp.
  • Search & Filter — Cari produk atau filter berdasarkan kategori.

Untuk Admin (Pemilik Toko)

Klik tombol Admin di menu header, lalu masukkan password.

  • Produk — Tambah, edit, hapus produk (nama, harga, stok, gambar, kategori).
  • Pesanan — Lihat semua order yang masuk, ubah status (NEW / PAID / SHIPPED / DONE), hapus.
  • Custom — Lihat request custom dan ubah statusnya.
  • Pengaturan — Ubah nomor WhatsApp yang digunakan untuk chat.

Semua perubahan langsung tersimpan di Google Sheets.

Fitur Database yang Aktif

  • Katalog produk dinamis (bisa diubah tanpa edit kode)
  • Riwayat pesanan lengkap
  • Request custom tersimpan
  • Manajemen stok otomatis
  • Panel admin dengan fitur CRUD penuh
  • Password admin disimpan aman di Apps Script (bukan di website)
